# SCADA

> 🚧 **Coming soon.** This section is a placeholder and will be filled in later.

**SCADA** (Supervisory Control and Data Acquisition) is the layer above the PLCs. It collects data from controllers across a plant, displays it on operator screens (HMIs), and logs alarms and history.

> **Prerequisite:** Do the [PLC track](../PLCs/) first. SCADA systems get their data from PLCs.
