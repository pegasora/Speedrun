# AI Data Analysis

Lectures and assignments from a university course on data analysis and machine learning. You'll go from loading and cleaning data, to classical models (regression, trees, clustering, SVMs), to neural networks with Keras.

## Folder layout

```
AI-Data-Analysis/
├── Lectures/      Lecture slides and notes, numbered in order
└── Assignments/   Hands-on programming assignments
```

## Setup

```bash
uv add numpy pandas matplotlib scikit-learn keras tensorflow
```

### Suggested grouping

| Block | Lectures | Focus |
|---|:---:|---|
| Working with data | 03–04 | Model overview, pandas, cleaning data |
| Classical models | 05–13 | Regression, Bayes, trees, ensembles, clustering, SVMs |
| Neural networks | 14–19 | Gradient descent, backpropagation, Keras, CNNs |

> If you're mainly here for vision, **lectures 14–19** are the most relevant. CNNs (lecture 19) are the foundation of most modern vision models.
