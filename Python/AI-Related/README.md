# AI-Related

Material on artificial intelligence and machine learning with Python. This section is **optional**, but it gives you useful background on how models learn, which helps when you start working with vision models.

> **Prerequisite:** Finish at least Chapters 1–10 of [Python Crash Course](../Intro/) first.

## Sections

| Section | Description |
|---|---|
| [AI-Data-Analysis](AI-Data-Analysis/) | University course on data analysis and ML: data manipulation, regression, Bayesian models, decision trees, clustering, SVMs, and neural networks |

## Resources

- [scikit-learn: Getting Started](https://scikit-learn.org/stable/getting_started.html): the main library for classical ML in Python
- [pandas: Getting Started Tutorials](https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html): loading and manipulating tabular data
- [Keras: Getting Started](https://keras.io/getting_started/): building and training neural networks
- [3Blue1Brown: Neural Networks](https://www.3blue1brown.com/topics/neural-networks): excellent visual explanations of how neural networks and backpropagation work
