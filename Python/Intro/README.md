# Intro to Python

## The book

📘 **[Python Crash Course, 3rd Edition](Python-Crash-Course-3rd-Edition.pdf)** by Eric Matthes

Read through it, get a grip on Python, and **type out and run the examples yourself**. Don't just read them. Get as far as you can or want, with this minimum:

| Requirement | What |
|---|---|
| **Required** | **Chapters 1–10** (Part I: Basics) |
| Recommended | Chapter 11, *Testing Your Code* |
| **Then** | **At least one project from Part II** (your choice) |

### Part I: Basics (Chapters 1–10, required)

| Ch. | Topic |
|:---:|---|
| 1 | Getting Started (installing Python and an editor) |
| 2 | Variables and Simple Data Types |
| 3 | Introducing Lists |
| 4 | Working with Lists |
| 5 | if Statements |
| 6 | Dictionaries |
| 7 | User Input and while Loops |
| 8 | Functions |
| 9 | Classes |
| 10 | Files and Exceptions |

### Part II: Projects (pick one or more)

| Project | Chapters | What you build | Good if you like… |
|---|:---:|---|---|
| **Alien Invasion** | 12–14 | A 2D game with Pygame | Games, real-time loops, event handling |
| **Data Visualization** | 15–17 | Plots and charts with Matplotlib and Plotly, plus working with APIs | Data, graphs, sensor-style data, which carries over well to vision work |
| **Web Applications** | 18–20 | A web app with Django | Websites, dashboards, servers |

## Tips

- **Do the "Try It Yourself" exercises.** They're where most of the learning happens.
- Keep your exercise code in your own folder (or your own Git repo), organized by chapter.
- Chapter 1 shows how to install Python. That's fine to follow, or you can use [uv](../README.md#uv) as described in the Python README.
- Stuck? Read the error message top to bottom, search it, then ask me.
