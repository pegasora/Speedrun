# ROS2

> 🚧 **Coming soon.** This section is a placeholder and will be filled in later.

[ROS 2](https://docs.ros.org/) (Robot Operating System 2) is a set of libraries and tools for building robot software. It isn't really an operating system. It's a framework for connecting pieces of robot software (nodes) that talk to each other over topics, services, and actions.

> **Prerequisite:** Do the [Robotics](../Robotics/) section first.
